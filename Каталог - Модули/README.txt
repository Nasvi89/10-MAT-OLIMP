Каталог «Блоки»

Здесь описана блочная структура олимпиадного трека по математике для 10В класса.
Каждый блок — одна олимпиадная тема. Движение по блокам каскадное:
следующий блок открывается только после «зачёта» по предыдущему.

Состав программы (по рабочей программе «Алгебра. Углублённый уровень», 10В):
1.  Степенная функция: степенная функция, корень n-й степени,
    степень с рациональным показателем, иррациональные уравнения и неравенства
2.  Тригонометрия: окружность и графики, знаки и чётность, основные формулы,
    формулы приведения, обратные функции и простейшие уравнения, методы
    решения, отбор корней, неравенства на круге
3.  Производная и её применение: производная, правила дифференцирования,
    касательная, исследование функций, экстремумы, построение графиков

Каждый блок состоит из тем (уроков) с конспектами.

У каждого блока три уровня глубины:
  • База  — школьная программа + минимум олимпиадных приёмов;
  • Актив — типовые олимпиадные задачи (школьный/муниципальный этап);
  • Олимп — задачи регионального уровня и нестандартные методы.

Контент блоков хранится в файлах:
../assets/data.js (метаданные и порядок),
../assets/theory.js (теория) и ../assets/bank.js (задачи).
